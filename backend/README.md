# Walking Mate - 백엔드 서버

Walking Mate 모바일 애플리케이션의 핵심 로직과 데이터베이스를 관리하는 API 서버입니다. Flutter 클라이언트의 요청에 따라 데이터를 처리하고, 외부 서비스와 연동하여 다양한 기능을 제공합니다.

<br>

## ✨ 주요 역할 및 기능

* **RESTful API 제공**
    * Node.js를 기반으로 사용자, 산책로, 커뮤니티 등 서비스의 모든 데이터에 접근할 수 있는 표준 API를 제공합니다.
    * JWT(JSON Web Token) 기반의 인증 시스템을 통해 사용자의 세션을 안전하게 관리하고 API 접근을 제어합니다.

* **AI 기반 산책로 생성**
    * Google Gemini API를 활용하여 사용자의 자연어 요청(경유지, 테마 등)을 분석합니다.
    * Naver Maps API와 연계하여 분석된 키워드를 바탕으로 최적의 산책 경로와 예상 소요 시간, 거리 등을 계산하여 제공합니다.

* **데이터베이스 관리**
    * MySQL 데이터베이스와의 통신을 담당하며, 사용자 정보, 산책 기록, 커뮤니티 데이터 등 모든 정보를 안정적으로 저장하고 관리합니다.
    * 업적 달성 여부, 포인트 적립/사용 내역 등 게이미피케이션 관련 데이터를 실시간으로 계산하고 업데이트합니다.

* **소셜 및 커뮤니티 기능**
    * **크루(Crew):** 크루 생성, 가입, 멤버 관리 및 크루 전용 게시판 기능을 제공합니다.
    * **워킹메이트(친구):** 친구 요청, 수락, 삭제 등 관계 관리 기능을 담당합니다.
    * **실시간 채팅:** Firebase Firestore와 연동하여 사용자가 워킹메이트와 1:1 채팅을 할 수 있도록 백엔드 로직을 지원합니다.

* **관리자 기능**
    * 사용자 신고 내역을 조회하고 '계정 정지', '회원 탈퇴' 등의 조치를 할 수 있는 웹 기반 관리자 콘솔 API를 제공합니다.
